# superdaddy · 超级奶爸工作台

> 本地优先的育儿记录工具——喂奶/睡眠/尿便/补剂打卡、疫苗排程、日龄速览。
> **宝宝的数据永不上传：零账号、零云、零请求，双击即用。**

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## 为什么

云育儿 App 要注册、传数据，还可能在某天开始收费才能导出你自己的照片。
超级奶爸工作台反过来做：**数据只存在你这台设备的浏览器里**，导出即拥有，
断网可用，代码开源可审计。

## Quick start（10 秒）

**直接用**：下载本仓库，双击 `index.html`（无需安装任何东西，无需联网）。

**或在线用**：待部署（地址见 release）

**或自托管**：任意静态服务器丢上去即可。

## 功能（v0.1）

- 🍼 **快捷打卡**：喂奶（侧别/时长/瓶喂量）、睡眠（含跨午夜）、尿、便、维生素D
- 📊 **今日速览**：日龄、喂奶次数与总量、睡眠时长、尿便、补剂
- 💉 **疫苗排程**：按生日自动排全程（免费/自费标注），待补提醒，一键标记已种
- 📝 **时间轴**：最近 3 天记录流，可删除
- 📦 **数据主权**：JSON 一键导出/导入备份；清空需双重确认
- 🔒 **零网络行为**：DevTools Network 面板为空（file:// 与部署版一致）

## 技术特点

零依赖、零构建：经典脚本 + localStorage，无框架无 CDN 无字体外链。
核心纯函数（日龄/疫苗排程/汇总）有完整单元测试（`npm test`，Node 内置测试器）。
